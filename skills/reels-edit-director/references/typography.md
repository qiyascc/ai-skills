# Typography: pairings and licences

Read this when choosing a font pair or when the user asks whether a font is free to use.

A brand video is commercial use, so the licence matters. Fonts marked **OFL** are under the SIL Open Font License from Google Fonts: free for commercial use, embedding in video included. Paid fonts need a licence from the foundry; a "free" download of a paid font is usually a demo for testing only.

## Pairings by mood

| Mood | Display (headlines, 1 to 4 words) | Support (subtitles, explanations) | Licence |
|---|---|---|---|
| Editorial, luxury | Playfair Display, DM Serif Display, Instrument Serif, Fraunces | Inter | all OFL |
| Bold, educational | Anton, Bebas Neue | Inter, Manrope | all OFL |
| Warm, personal | Fraunces (soft, high optical size) | Nunito, Lato | all OFL |
| Minimal, tech | Montserrat ExtraBold, Space Grotesk Bold | Inter, Space Grotesk Regular | all OFL |
| Fashion, statement | Clash Display | Inter | Clash Display: free on Fontshare (ITF Free Font License, commercial use reported allowed; check the licence on fontshare.com) |

Premium alternatives when the brand already owns them:

| Font | Foundry | Licence |
|---|---|---|
| Canela | Commercial Type | Paid. Its EULA also restricts AI and generative use |
| Druk | Commercial Type | Paid |
| Recoleta | Latinotype | Paid; the free download on font sites is a demo for testing only |

## Rules that make a pair work

- **Contrast of job, not just of shape.** Display is loud and rare; support is quiet and everywhere. If the support font starts appearing in headlines or the display font in subtitles, the hierarchy collapses.
- **One weight jump is enough.** Display in black or bold, support in regular or medium.
- **Condensed display fonts** (Anton, Bebas Neue) fit big words into a narrow column beside a face, which is why they dominate talking-head edits.
- **Serif display** reads as slower and more premium; pair it with slower music and fewer cuts.
- **Case:** all caps for 1 to 3 word punches; sentence case for anything longer, because all-caps sentences read slowly.
- **Colour:** text in one neutral plus one accent. The accent marks the single key word, the same way every time.
- **Mobile check:** display text should be readable at arm's length on a phone; as a starting point, at least about 70 px cap height on a 1080×1920 canvas for headlines and 40 to 48 px for subtitles. Adjust to the font.

## Letters and languages

- Check that both fonts contain every letter the script needs before choosing them: Turkish needs İ ı Ş ş Ğ ğ Ç ç Ö ö Ü ü, Azerbaijani adds Ə ə, and many display fonts ship without some of these. A missing letter falls back to a different font mid-word, which looks broken.
- Type all-caps text in capitals yourself instead of relying on an automatic uppercase switch: some apps convert i to I instead of the Turkish and Azerbaijani İ.
- Google Fonts lists the supported languages on each font's page; filter by language there.

## In the editor

- CapCut, Edits, Premiere and DaVinci all accept installed system fonts on desktop. On phone apps, check the app's own font list first; importing custom fonts is not available everywhere.
- Save the pair as a text preset or template once, so every video in the series uses the same sizes and spacing.
