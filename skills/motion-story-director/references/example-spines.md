# Example spines

Patterns from top-tier prompts. Use them to calibrate how much happens per second and how the hero carries every transition; do not copy them.

- **Sketch to motion (13.4 s, 24 fps):** hand-drawn icon → morph into app icon → typed prompt → 6 option cards burst out → cards become a zig-zag the ball hops along (process) → loader ring → play button → iris to brown → big starburst + two-line slogan. Hero: starburst in every form.
- **Focus mode (15.13 s, 30 fps, loop):** glossy button + orbiting notifications → bubbles smash an equalizer → red reticle targets distractions → apps blocked with red ✕ → "Do not disturb" → shutter/iris into focus → tasks flip to ✓ → progress ring → calm orbit → defocus to match frame 0.
- **Subscription saver (15 s, 152 BPM):** living blob → 5 renewal banners → $74.91/mo odometer → $899/yr → blob turns red → cancel 4 → list moves to Inactive → "Saved $743/yr" → savings drop into the Dynamic Island while music plays.
- **Search to find (16 s, 158 BPM):** app icon tap → dive into its dot → dot becomes "you are here" on a 3D city → pin + sheet → play sound rings → dive to street level → precision arrow countdown → green "Here" iris → macro of the object → icon closes around it (loop).
