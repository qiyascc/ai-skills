# AI skills

Skills for coding agents by [Qiyas CC](https://qiyas.cc/). Each skill is a single `SKILL.md` file in `skills/<name>/`.

## Install

From GitHub:

```
npx skills add qiyascc/ai-skills
```

From qiyas.cc:

```
npx skills add https://qiyas.cc
```

The command finds the agents on your machine (Claude Code, Codex, Cursor, OpenCode and more) and lets you pick the skills. Add `--skill <name>` for one skill and `-g` to install it for every project.

You can also download any `SKILL.md` by hand from [qiyas.cc/ai-skills](https://qiyas.cc/ai-skills/) and put it in your agent's skills folder, for example `~/.claude/skills/<name>/SKILL.md`.
